## Decisions that apply everywhere (made once; do not re-decide)

1. **Design rules:** adopt the "Design rules to adopt" list in `findings-design.md` (type scale, mono label spec, one frame, at most one boxed primary action per view and text links for secondary actions, one input style, `.seg` for <= 5 choices, one tab style, mint budget, one categorical palette, network figure style, number and date formats). F4 implements the tokens and shared classes in `theme.css` / `app.css`; every other area uses them and deletes local look-alikes.
2. **Spelling and terms:** American spelling (the site is American: color, organization, neighborhood, analyze). "Person / people" and "tie(s)" in the interface (not node / edge / link / alter in visible text, except where the term itself is being taught, e.g. "alters (the people named)"). Sentence case. Dates `6 Jan 2025`, weeks "week of 6 Jan 2025". No scientific notation in the UI (show ~0 or fixed decimals).
3. **Plain language without dumbing down:** keep standard names (Betweenness, Constraint...) because experts need them, but wherever a measure is shown as a row (network panel, profile, groups reading), show a one-line plain gloss under or beside it (from the glossary's meaning text), not only on hover. Statistical outputs (z, p, d_z, E-I) always come with a plain verdict sentence first, numbers second.
4. **Whose network:** personal exports each name an owner (egoKey). When two or more ego sources are loaded, the Data review asks "Are these all you?" listing each owner, defaulting to merged; merging uses `applyMerges`. A manual "Same person as..." merge is always available (Data "Who is who" and the person profile), not only when suggestions exist.
5. **Deactivated / departed accounts:** importers record them (`attrs.deactivated = true`, e.g. Slack `deleted`), the import report counts and names them, People / Network / reports badge them, and shift explanations say "stopped appearing" when that matches.
6. **Generated data:** the Generate view stores `store.generated = { datasetName, spec, groundTruth, recovery }` (new store field). Network shows a compact recovery banner with a link to the full panel whenever `store.generated` matches the loaded dataset; the full panel lives in Generate and survives navigation. Planted groups are labeled "Planted group (ground truth)", never "Community".
7. **Nothing silently replaces data:** when data is loaded, new imports default to Add; Replace requires an explicit choice. A header chip always shows what is loaded ("Analysing: <short name>") with a Start over action; leaving or reloading the page with data loaded warns that nothing is stored.
